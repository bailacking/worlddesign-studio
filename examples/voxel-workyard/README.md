# 块石工场

从仓库根目录运行 `python scripts/launch.py voxel`。构建目录与默认值 `build/native` 不同时，用 `--build` 指定。

1. 点击方块视口，站在出生点附近，按 **E** 登车。
2. 按 **D** 向东穿过区块边界。轨道在 X=18 结束。用 **A** 返回，用 **E** 下车。
3. 摄像机朝北，稍向下看。按 **F** 推进一轮水和火。北面的石台上有泉水下落、火被水扑灭，以及另一处木材逐块引燃。
4. 在工作台按 **Ctrl+S** 保存方块状态。要保留初始布局，可以复制项目目录，再以 `--project` 打开副本。

| 项目操作 | 模式 | 输入 |
| --- | --- | --- |
| `scene.voxel.cart` | `read` | 起点 `x`、`y`、`z`，一个水平轴的单位方向 `dx`、`dz`，及 1–64 步。返回经过的格子和是否提前停下。 |
| `scene.voxel.dynamics` | `preview`、`apply`、`cancel` | 最小 `x`、`z`，各为 1–24 格的 `width`、`depth`，及 1–32 步。返回水格更新、被引燃的木材和被水熄灭的火格数。 |

水优先下落，有承托才在同一高度向四邻降级扩散。水和火按每轮开始的快照计算，水先于同轮火的传播生效。火一轮后消失，可引燃四邻木材。区域边界封闭，工作台的 **F** 使用以玩家为中心的 17×17 区域。提交通过项目修订检查。矿车的乘坐位置属于临时试玩状态。

运行 `ctest --test-dir build/native -R '^living_systems$' --output-on-failure` 可重放跨区块、预览、保存重开和旧修订拒绝。
