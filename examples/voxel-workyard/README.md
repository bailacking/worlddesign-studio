# 块石工场

从仓库根目录运行 `python scripts/launch.py voxel`。构建目录与默认值 `build/native` 不同时，用 `--build` 指定。

1. 点击方块视口，站在出生点附近，按 **E** 登车。
2. 按 **D** 向东穿过区块边界。主轨在 X=18 结束。在 X=17 可按 **S** 两次进入岔道，再按 **A** 转向西侧。用 **E** 下车。
3. 摄像机朝北。按 **F** 推进一轮流体和火。北面的石台上有泉水下落、火被水扑灭，以及另一处木材逐块引燃。更北的高石台上，水与熔岩在 X=16、Y=6、Z=10 交会形成玄武岩。
4. 在工作台按 **Ctrl+S** 保存方块状态。要保留初始布局，可以复制项目目录，再以 `--project` 打开副本。

| 项目操作 | 模式 | 输入 |
| --- | --- | --- |
| `scene.voxel.cart` | `read` | 起点 `x`、`y`、`z`。可指定直线的 `dx`、`dz` 和 `steps`，也可用 `directions` 列出逐格方向。最多 64 步。返回经过的格子和是否遇断轨。 |
| `scene.voxel.dynamics` | `preview`、`apply`、`cancel` | 最小 `x`、`z`，各为 1–24 格的 `width`、`depth`，及 1–32 步。返回水格更新、被引燃的木材和被水熄灭的火格数。`workyard-v2` 同时返回 `lava_updates` 和 `solidified`。 |

水优先下落，有承托才在同一高度向四邻降级扩散。水和火按每轮开始的快照计算，水先于同轮火的传播生效。火一轮后消失，可引燃四邻木材。区域边界封闭，工作台的 **F** 使用以玩家为中心的 17×17 区域。提交通过项目修订检查。矿车的乘坐位置属于临时试玩状态。

运行 `ctest --test-dir build/native -R '^living_systems$' --output-on-failure` 可重放跨区块岔道、预览、保存重开和旧修订拒绝。回归还用电路把水闸石块从 X=15、Y=7、Z=9 移到相邻空格，验证下一轮泉水流经原闸位。
