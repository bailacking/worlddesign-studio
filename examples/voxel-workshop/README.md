# 方块工坊

将本目录复制到可写的位置，在 WDS 工作台中选择 **项目 → 打开项目**。项目会直接进入第一人称编辑视口。

- **WASD** 移动，**方向键** 转头，**空格** 跳跃。
- 瞄准方块后用 **左键** 破坏，用 **右键** 在命中面的相邻格放置。准星旁显示命中的格子坐标，射程为 7 格。
- **Ctrl+S** 或 **项目 → 保存方块世界** 写入当前项目修订。关闭再打开可看到保存的地形。使用 **放弃方块草稿** 恢复到已保存的地形。

出生点正对石墙。先右键放一块石头，然后向右横移一格，左键拆掉另一块石头，保存并重开即可核对两个改动。

天空颜色、默认放置方块、三个方块材质的颜色和破坏规则在 `assets/stone-colors.txt`。修改后重开工程加载。
