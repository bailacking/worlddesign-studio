# 荒地营火

在工作台打开后点「试玩」，用 **F6** 开启「物品与配方」。Windows 玩家版用 **Tab** 开关面板，方向键选操作，Enter 执行。打开面板期间场景暂停。

1. 出生点旁采集 `twigs`，拾取 `twig`。
2. 关面板，向右走到石堆和浆果之间。开启面板，采集 `stones`、`berry-bush`，拾取 `pebble` 和 `berry`。
3. 合成 `build-campfire`，再烹饪 `cook-berries`。成品是 `stew`，同时解锁 `make-lantern`。有剩余木料即可制作提灯。采集点次数有限，重新试玩时回到空背包和起点。
