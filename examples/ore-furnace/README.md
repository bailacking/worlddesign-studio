# 矿炉起步

用 WDS 工作台打开本目录的副本。出生时背包为空，面对准星连续左键四次，依次挖到 3 份矿石和 1 份泥炭。按 **F6** 打开「物品与配方」。

1. 拾取 `ore` 和 `peat`，选 **合成 build-furnace**。面板按已定义的两格配方从背包配料，得到炉子并解锁熔炼。
2. 选 **熔炼 smelt-ingot**，矿石加泥炭得到 `ingot`。可把矿锭存入箱子并取出。
3. 关闭面板，点「保存世界」并重开。矿坑、背包、掉落、箱子和炉子解锁记录一并保存。右键放置会消耗对应材料。
