## 版本证据

**Java 1.16.5。** 重验本机 W2 的 Mojang 元数据及客户端、服务端文件长度和 SHA-1。两端内置版本相同，世界数据版本为 2586，协议为 754。W2 生成的报告列出 763 个方块、976 个物品、108 个实体类型、32 个状态效果和 15 个村民职业注册项。发布包内抽查到 167 份堡垒遗迹、20 份末地城和 482 份村庄结构模板，另有龙的进度条目、猪灵交换数据及袭击者标签。这些是注册或文件计数，每份模板或注册项是否可用仍需运行验证。 [Mojang 版本公告](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-16-5) · [Java 下界更新说明](https://www.minecraft.net/en-us/article/nether-update-java)

Mojang 说明和原版方块报告均显示重生锚充能上限为 4。WDS 现在支持按站点配置锚点容量，旧文档缺省为 3。铜脊接力配置为 2，回放覆盖满额时不扣道具、不推进时间，以及消耗一次充能后返回锚点。原版实际交互和死亡重生尚待实跑。 [方块基准](voxel-benchmark.md#w2-逐领域对照)

**《饥荒》PC 单机候选构建 `198251`。** Klei 的该构建公告是翻译相关热修，证明候选构建身份。较早的 `193934` 公告记载了跨世界猎犬进度、火山状态和兼容存档开关。 `197843` 公告记载巨人国春夏默认设置的修复。上述证据支持复验用例。发起人已确认暂无可运行历史版，目标环境中的实际结果登记为缺证。 [构建 198251](https://kleiforums.com/game-updates/sw/198251-r159/) · [构建 193934](https://kleiforums.com/game-updates/sw/193934-r134/) · [构建 197843](https://kleiforums.com/game-updates/sw/197843-r154/) · [饥荒基准](dontstarve-benchmark.md#w2-历史构建取证)

开始补证前按[参考游戏先查资料再实测](../engineering/quality.md#参考游戏先查资料再实测)联网核对目标版本资料，列出仍需动态观察的用例。有合适的原版环境时，记录发行渠道、版本或构建号、DLC 开关和测试存档来源。使用隔离副本，台账保存实验条件、观察结果和证据。

## W24 Windows 补验

四轮从空工作目录开始。每轮跑两条完整原创路线，分别为 39 和 48 个成功动作。两个项目都先以修订 0 运行，然后通过项目操作更改饥饿间隔和远征地形种子，以修订 2 完整重跑。每轮导出两个项目各两份，共 16 份 Windows 独立包通过完整性检查和图形冒烟。以下时间均为单轮测量，打包和启动列为每轮四份包的合计。

| 种子 | 站点数 | 生成工程 | 原路线、反例回放 | 中断复验 | 诊断修补、续编与重跑 | 打包与两种启动检查 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 73021 | 43 | 13 ms | 419 ms | 91 ms | 330 ms | 3.18 s |
| 73021 | 475 | 14 ms | 389 ms | 95 ms | 387 ms | 3.18 s |
| 16431 | 475 | 15 ms | 363 ms | 95 ms | 364 ms | 3.16 s |
| 4294967295 | 475 | 15 ms | 374 ms | 94 ms | 374 ms | 3.08 s |

三轮高负载各生成 18 个图标 PNG 和 36 个地形色。规则展开每轮约 0.55–0.59 ms，配色与图标生成约 0.72 ms。单份包写出约 62–99 ms，完整性检查约 120–152 ms，原生图形冒烟约 565–641 ms。额外站点主要来自同类规则展开，数量只反映该批次的规模。以上数据衡量已有生成器和工程流水线，未计参考研究、从题目现场编写项目、独立验收或模型用量。
