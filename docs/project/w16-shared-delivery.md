# W16 双类型交付

截止时间为北京时间 2026 年 11 月 20 日 22:00。2026 年 11 月 18 日在 Windows 11 x64 完成本机验收。工作台使用 Qt 6.8.3，发行使用 raylib 独立播放器。

## 项目交付

| 样品 | 编辑与试玩 | 独立导出及续编 |
| --- | --- | --- |
| 「风标接力」二维 | 新建场景，编辑玩家与目标。离线适配器的已确认建议写入修订 2，试玩角色从 x=-112 移至 x=-84 | 初版修订 2。交给人工后调整玩家起点，保存修订 3 并重新导出 |
| 「坡地营地」三维方块 | 新建种子 73021 的工程，摆放方块。试跑可跨至 x=17.5。切为琥珀暮色并恢复日光 | 初版修订 3。接手续摆第三块，保存修订 4 并重新导出 |

四份包均通过 `Play.exe --check`。两个续编包从包外目录、仅含 System32 的 PATH 启动，Windows 原生窗口均收到移动输入。工作台 F5 试玩可临时拆块，Shift+F5 停止后恢复编辑画面，保存的场景摘要保持一致。用 W14 播放器套件导出二维项目通过，方块项目在创建成品目录前提示需要 `voxel_format`。

用工作台的 **项目 → 新建工程** 选择二维或三维方块。二维用属性区编辑，三维用视图直接编辑。保存后按 **F5**，按 **Shift+F5** 返回。通过 **项目 → 导出 Windows x64** 生成独立目录。把工程目录一并交给下一位创作者续编，保存新修订后导出到新目录。

## 插件替换与恢复

方块场景通过 `PluginHost` 选择内置配色提供者 `daylight` 或 `amber-dusk`。用 **场景 → 方块配色** 选择已安装的提供者，可用 **Ctrl+Z** 撤销本次替换。共享操作 `scene.palette.set` 会返回变更前后的场景内容。CLI 可预览，提交后可对调变更内容并调用 `scene.restore`。恢复校验场景原文和预期修订，避免覆盖并发编辑。

Windows 工作台的原生窗口中，天空色从 `#87BCE8` 切到 `#857EAC`，按 Ctrl+Z 后恢复。试验副本的修订从 4 增至 6，场景与替换前逐字节相同。共享操作也验证了不存在的提供者被拒绝，已保存的提供者保持可用。这轮覆盖内置能力的配置替换，外部二进制的热卸载与迁移留待独立验证。

## AI 接手

操作员通过 `scripts/project_agent.py` 选择适配器、授予特定编辑操作、预览候选修改并逐次确认提交。暂停会阻止新建议与提交。撤权清除授权和待提交内容。人工接管锁住 Agent，保留当前项目修订，创作者可从普通工作台或 CLI 继续。

同一会话切换两套离线适配器后，调用和 Token 计数继续累积。三次离线调用中只有一次写入项目。第三次适配器回报的模拟 Token 合计达到 77，高于 70 的预算，候选写入被拒绝。用量由适配器上报，真实模型与供应商账单待接入验证。
