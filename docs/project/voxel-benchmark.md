# 方块项目验收基准

[50 周开发计划](50-week-plan.md)的参考目标为 **30 分钟内从零资产复刻《我的世界》Java 1.16.5**。可运行、可编辑的产物都必须在限时内交付。参考以 Mojang 官方客户端和服务端为准。版本元数据证明版本身份，规则和数值另用版本资料及原版实测核验。原版协议互通、存档格式、账号及外部服务边界由发起人在 W2 确认。 [官方发布公告](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-16-5) · [版本元数据](https://piston-meta.mojang.com/v1/packages/fba9f7833e858a1257d810d21a3a9e3c967f9077/1.16.5.json) · [Java 下界更新说明](https://feedback.minecraft.net/hc/en-us/articles/360044911972-Minecraft-Java-Edition-Nether-Release)

## 全量矩阵

以下领域用于组织 W2 盘点及后续取证。保留每组可验证条目数、已执行数、缺证及经确认的不适用项。

| 领域 | 逐项核对范围 | 平台任务 |
| --- | --- | --- |
| 创建、设置与存档 | 创建、模式、种子、难度、设置、暂停、死亡、重生、存档、备份和恢复 | PRJ-04、RUN-01、PKG-02 |
| 世界与探索 | 主世界、下界、末地，群系、地形、结构、门户、矿物、植被、区块、天气与时间 | VOX-01、VOX-05、VOX-08 |
| 方块、环境与自动化 | 完整方块及状态、材料、放置与破坏、液体、火、光照、种植、红石时序、准连接性、活塞、轨道 | VOX-02、VOX-05、VOX-07 |
| 玩家与生存 | 移动与碰撞、游泳、骑乘、生命、饥饿、伤害、战斗、状态效果、重生 | RUN-04、VOX-04、VOX-06 |
| 物品与制作 | 所有物品和变体、背包、容器、配方、加工、维修、酿造、附魔、交易、耐久 | VOX-03、VOX-04、VOX-06 |
| 生物与载具 | 刷新、AI、繁殖、驯养、骑乘、掉落、村民及袭击、首领、矿车与船 | VOX-06、VOX-08 |
| 玩家工具与表现 | HUD、菜单、四种游戏模式、输入、音画提示、资源包、指令、数据包、统计、进度与调试 | VOX-09、EDT-04、RUN-03 |
| 多人 | 局域网和独立服务端、加入退出、权限、同步、掉线重连、服务端存档 | RUN-07、VOX-10 |

每项记录稳定 ID、版本、模式、前置条件、操作、原版与 WDS 结果、证据及阻塞能力。数据条目批量验证，玩法顺序保留重放场景。不能直接用跨版本通用资料代替 1.16.5 的观察。通用玩法能力另用原创任务验证。

## 计时及续编

按 [最终验收口径](50-week-plan.md#二最终验收口径) 从空工作区执行。只预装清单内的通用工具与能力。目标游戏的项目代码、数据、资产和生成器在计时内产生。封存停表时的产物，长局和全量对照使用同一份成品。修改后的产物须重新计时。

验收报告列出用时、Token、环境、尝试与人工干预，保留同模型无 WDS 对照。范围内须无缺项、实质偏差和关键缺证。材质纹理允许略有差异，仍核验操作提示与辨识度。另由创作者修改一项内容和一条规则，保存重开、试玩并重新导出。原创方块盲题单独在 60 分钟内交付并按同量级评分表评估。
