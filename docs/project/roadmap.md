# 实施路线

## 当前阶段

WDS 以通用游戏开发平台为交付主体。已验证的 C++ 工程、插件、资源操作和方块样例见 [前期原型与验证](prototype-baseline.md)。当前优先贯通从 [桌面工作台](../architecture/workbench.md)编辑、试玩到 Windows 独立交付的路径。阶段任务见 [开发任务](development-tasks.md)，多人认领与合并顺序见 [并行开发计划](parallel-delivery.md)。

逐周交付与验收以 [50 周开发计划](50-week-plan.md)为准。W4 已更新全量工作量与日期情景，50 周仍为冲刺目标。 [工期更新](w4-benchmarks.md#工期更新)

阶段 B 已在 Windows 跑通入口场景实体编辑、试玩及会话内撤销重做，工作台与 CLI 共用场景和数据资源的导入及恢复。工作台采用共享主题和面板组件，CI 检查样式及文档入口。接下来补更多资源类型和独立导出。[长期维护](../engineering/quality.md#长期维护)

| 阶段 | 主要交付 | 进入下一阶段的证据 |
| --- | --- | --- |
| A 工程底座 | 项目清单、资源身份、版本迁移、事务恢复、共享操作协议及桌面编辑框架选择 | 合法与异常项目可复跑验证，旧数据有迁移或保留路径，预览不修改项目 |
| B 创作闭环 | 编辑器工作台、场景和属性、资源导入、试玩、共享 CLI、Windows 导出 | 同一项目可从 GUI 和 CLI 编辑，保存重开一致，导出后可独立运行 |
| C 可复用生产 | 版本化能力包和模板、逻辑与调试、AI 工作流、跨平台和生态工具 | 方块项目与非方块项目共享编辑发布流程，另一个创作者可继续修改 |
| D 全量验证与发行 | 两款参考复刻、两款原创盲题、平台核心要求和跨平台发布 | 两项 30 分钟与两项 60 分钟各自通过，成品可独立运行，人工可续编 |

[方块](voxel-benchmark.md)和[饥荒](dontstarve-benchmark.md)参考项目并行核查。通用需求进入项目、编辑器、运行时或发布接口，领域玩法进入可复用能力包，普通内容归入参考项目。每项记录原版与 WDS 行为、耗时、Token 和人工接手证据。
