# Minecraft Java 版 1.6 参考资料目录

资料日期：2026-11-14。本文是 REF-01 的检索目录，供 [方块项目验收基准](../project/voxel-benchmark.md) 的八个领域逐项扩充与核验时使用。范围限 1.6 系列（以 1.6.4 为主参考，1.6.1、1.6.2 补差异）。**本目录不统计完整内容矩阵，不含任何原版游戏资源**；条目只记录入口、版本、覆盖项和仍待实测的问题。

## 核对口径

- **版本身份以官方元数据为准**：`version_manifest_v2.json` 与各版本 JSON 可给出类型、时间戳、客户端与服务端哈希、资源索引和启动器下限。官方公告原文本次不可达，见 [缺口汇总](#缺口汇总)。
- **社区页面只作导航和线索**：Minecraft Wiki 的主题页默认按当前最新版本（本次核对时站点正文涉及 26.1 至 26.3 的重构）编写，不能直接回填到 1.6.4；版本页（`Java Edition 1.6.x`）才是按版本组织的增删改条目。
- **证据类别**分五档：官方元数据、社区版本页、社区主题页、社区指南、缺陷单。**社区记载与原版实测分开记录**，本目录不含任何实测结论。
- **核对程度**分两档：`正文已读` 表示本次读取了页面正文并据此填写覆盖项；`仅存在性` 表示只确认页面存在（`api.php` 返回 pageid 与 lastrevid，或 HTTP 200），覆盖项按页面标题推断，扩写前须读正文。

## 缺口汇总

1. **官方发布公告不可达。** 社区页引用的 Mojang 博客地址 `mojang.com/2013/07/minecraft-the-horse-update/` 现以 301 跳转到 `minecraft.net/en-us/2013/07/...` 并返回 404；本次另测 `minecraft.net` 的多条候选文章路径均 404。档案站可用性接口对该地址返回 200，但直接抓取被限流（HTTP 429），正文未核对。因此 1.6.1 的官方公告只能记为“存在但当前不可访问”，版本身份依赖官方元数据与社区页交叉。
2. **社区主题页存在版本漂移。** 八领域引用的主题页均按当前版本编写，其中 `level.dat`、天气存放位置、方块存储方式、数字 ID 体系在 1.6.4 之后都发生过重构。这些页面只能当索引用，条目上的数值必须换旧修订（`oldid`）或实测。
3. **修复条目计数不可作验收数字。** 本次核对所见：1.6.1 英文页记 86 项修复、中文页记 76 项；1.6.2 英文页 71 项、另一修订 72 项、中文页 55 项。计数随语言与修订变化，只能作检索线索。
4. **缺陷单正文不可机读。** `bugs.mojang.com/browse/MC-31065` 等地址返回 HTTP 200，但正文由脚本渲染并需登录态，本次未核对标题与修复版本；版本页列出的缺陷编号只能作待核清单。多人域因此不设独立缺陷单条目。
5. **1.6.4 的存档字段与协议细节未测。** 是否含 `DataVersion`、天气与生成器字段在 1.6.4 的实际键名、协议 78 的包定义，全部属于待实测项；本目录不给出结论。
6. **原版资源不在范围内。** 音效、纹理、语言文件与界面贴图一律不收集、不提交；需要判断外观或音频时，只在验收记录中写明验证条件与所需资料。
