# 平台与交付

## 平台方向

桌面优先，Windows、Linux、macOS 纳入首期架构和可行性研究；Web 是目标方向。首个实现平台、最低系统版本、设备要求和发布次序尚未确定，不承诺全部平台同时交付。

## Web 范围

浏览器运行游戏、浏览器编辑器和远程访问桌面宿主是不同能力，应分别定义。原生动态插件、文件访问、线程、图形后端和网络限制可能影响浏览器实现，需要明确替代与降级策略。

离线架构说明页面是一份文档，不构成 Web 引擎或 Web 编辑器支持的证据。

## 当前支持矩阵

| 平台／能力 | 当前状态 | 需要的证据 |
| --- | --- | --- |
| Windows 桌面创作与运行 | 现代工作台已实测项目编辑、保存和二维试玩 | 独立发行、导出、正式输入与图形后端、插件组合仍待验证 |
| Linux 桌面创作与运行 | 默认核心构建和测试已有 CI；现代工作台与发行待验 | 相同任务与原生环境结果，记录图形和文件系统差异 |
| macOS 桌面创作与运行 | 规划中、未验证 | 相同任务与原生设备结果，记录工具链与分发约束 |
| Web 游戏运行 | 范围评估中 | 浏览器、图形、资源加载、包体与输入限制 |
| Web 编辑与远程访问 | 范围评估中 | 存储、权限、协议与功能差异 |

## 发布要求

每个发行版本声明可支持任务、插件组合、依赖和最低环境。验证安装、升级、卸载、项目迁移及恢复；说明未覆盖的设备与已知问题。构建成功不等于运行支持，其他操作系统的结果不能代替本机平台证据。

发布包只含需要的内容和许可声明。公共地址、签名、更新渠道及发布权限在实际发行流程建立时确定。
