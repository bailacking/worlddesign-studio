# 桌面工作台

## 第一版交付

工作台采用可调整的编辑器布局。顶部是菜单、项目名称与修订、保存、撤销和运行控制。左侧为场景树，中央为场景视口，右侧为属性检查器，底部为资源和输出页签。面板可以隐藏和恢复，布局随工作台设置保存。首轮使用清晰的深色界面，突出选中、修改中、失败和运行中状态，保留键盘焦点提示与原生交互。

第一条正式创作路径是打开项目、选中实体、修改一个真实属性、保存并试玩。窗口内能判断改动是否已保存、试玩用了哪个修订、失败发生在哪个资源。Qt 工作台是通用项目的桌面入口。整数数据字段可通过 **编辑 → 编辑整数数据字段** 预览与提交，事务恢复通过 **项目 → 恢复项目**。用 **项目 → 导入资源** 选择场景、数据、PNG 或 UTF-8 文本，或拖入单个支持的本机文件。预览确认后提交。资源面板显示来源、PNG 缩略图和文本摘要。通过 **项目 → 导出 Windows x64** 把保存修订放入新的游戏成品目录。 [导出步骤](../engineering/development.md#导出-windows-x64-游戏)

## 首版技术路线

首版采用 **Qt 6 Widgets**，这是可替换的编辑器前端。用 `QMainWindow` 与停靠组件实现面板，场景视口独立于窗口布局。先交付 Windows x64 构建；最低 Qt 6.8，实际使用的补丁版、安装来源与构建命令由 WKB-01 记录。本地已从 Qt 下载仓库获取 Qt 6.8.3 MSVC 2022 x64 SDK。可在独立构建目录编译并运行现代工作台。核心和 CLI 沿用 C++20 与现有默认构建。使用 `WDS_BUILD_MODERN_STUDIO` 显式启用，Qt 目标的运行库配置与所选 SDK 一致。编辑器发行任务负责 Qt 运行库、许可材料及第三方声明。 [停靠组件](https://doc.qt.io/qt-6/qdockwidget.html) · [高 DPI](https://doc.qt.io/qt-6/highdpi.html) · [Windows 工具链](https://doc.qt.io/qt-6.8/windows.html) · [Qt 开源分发说明](https://www.qt.io/development/open-source-lgpl-obligations)

首版 UI 异步调用同一构建的 `wds_cli` 进行项目查询和写入。请求完成前禁止切换项目和提交另一条改动。项目数据由 C++ 项目服务验证和落盘。二维视口直接读取共享 C++ 会话的逐步状态，正式图形与输入适配由 SIM-01 和 WKB-08 继续推进。

## 模块边界

| 模块 | 读取 | 交互与状态 |
| --- | --- | --- |
| 工作区 | 项目 ID、路径、修订及可用操作 | 打开、创建、关闭、恢复布局。真实动作启用状态由当前项目决定 |
| 场景树 | 入口场景实体及稳定 ID | 选择和搜索。通过场景菜单新建、复制、删除和排序。实体层级由场景数据模型提供后接入 |
| 属性 | 当前实体及字段类型、当前值、范围与默认值 | 修改后先保留草稿，提交时带预期修订。失败或冲突保留草稿并定位字段 |
| 资源 | 项目资源 ID、类型、路径、引用 | 搜索与选择。导入、移动和删除经共享操作执行 |
| 视口 | 编辑态场景或指定修订的试玩会话 | 选中态联动。试玩可接收方向输入，显示精灵和结果。失焦暂停并清键，停止后恢复编辑视图与焦点 |
| 输出 | 操作、运行及导出诊断 | 记录时间、级别、资源、字段和修订。能定位来源时提供跳转 |

当前 Windows 构建已接入工作台主题、场景树和资源面板。资源区显示 ID、类型、路径以及选中资源的直接引用和被引用项，支持搜索与筛选。资源移动与删除仍由 PRD-04 推进。

**设置 → 界面语言**可即时切换简体中文与英文，工作台会记住选择。切换时保留正在编辑的项目、属性草稿与过滤条件。项目 ID、资源路径、修订和诊断码使用源值。

## 组件与交互规范

窗口与面板沿用 Qt Widgets 和当前主题。新增界面先用 Qt 原生控件和现有面板组合，从下表找接入点。新样式与确有用途的变体集中写入全局主题。

| 要复用的部分 | 入口与行为 |
| --- | --- |
| 全局样式与绘制颜色 | `src/studio/theme/colors.inc` 保存语义颜色。QSS 用 `@名称@`，C++ 用 `theme::color::名称`。Qt 调色板、视口、输出颜色读自同一来源 |
| 面板间距、列表和空态 | `theme::configurePanelLayout`、`theme::configurePanelTree`、`theme::makeEmptyState`。新面板沿用统一的边距、行选择和键盘焦点 |
| 场景实体选择 | `SceneTreePanel::setEntities` 和 `setSelectedId`。按输入顺序显示，支持搜索、键盘选择与清空 |
| 资源浏览与引用 | `ResourcePanel::setResources` 和 `setSelectedId`。按稳定 ID、路径及类型筛选，能查看引用和导入来源 |
| 输出与错误 | `OutputPanel::setEntries` 接受已本地化的文本与级别，项目服务提供稳定错误码，工作台负责翻译和定位 |

工作台保持系统字体和 DPI 缩放。焦点与选中可以区分，禁用、运行、失败和未保存有文字或动作状态可辨。空项目与无搜索结果分别提示。场景树和资源面板在用户主动选择时回调一次稳定 ID，程序同步时保持静默。筛选隐藏的选择在清除条件后恢复。切换项目时清除原选择与输出，切换语言时更新显示文本和辅助功能标签。

新增保存或提交动作应复用项目服务和桥接层，保持草稿状态、修订约束和失败后的恢复方式可理解。涉及键鼠、焦点、翻译或 DPI 的变更，选一条真实项目路径在工作台验收。 [实施任务与分工](../project/parallel-delivery.md)
